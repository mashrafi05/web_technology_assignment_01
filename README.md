# Explore Bangladesh — HTML & CSS Website

A six-page responsive travel website built with HTML5 and CSS3 only.

## Pages
- `index.html` — Home
- `destinations.html` — Destinations
- `packages.html` — Travel packages (sample concepts and illustrative budgets)
- `gallery.html` — Gallery
- `about.html` — About the project
- `contact.html` — Contact form design

## Run the website
1. Download and extract the complete ZIP archive.
2. Keep all six HTML files and `style.css` together in the same `explore_bangladesh` folder.
3. Open `index.html` in a browser, or open the folder in VS Code and use Live Server.
4. Navigate between the pages using the menu at the top.

**Important:** Do not move an HTML page out of this folder by itself. It needs the adjacent `style.css` file. The website photographs are loaded from Unsplash, so an internet connection is required for the images.

## Technologies
- HTML5 semantic elements
- CSS custom properties, Flexbox, Grid, media queries, transitions, animations and pseudo-elements
- No JavaScript

The contact page is a front-end form demonstration; it does not send messages to a server.
